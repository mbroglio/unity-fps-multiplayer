# 🎮 First Person Shooter — High School Project

A 3D first-person shooter game developed with **Unity** during the 3rd year of High School.

## 🗂️ Project Structure

| Folder | Description |
|--------|-------------|
| `3D First Person Shooter - Game/` | Main game client (Unity project) |
| `3D First Person Shooter - Server/` | Multiplayer server project |
| `3D First Person Shooter - SinglePlayer/` | Standalone single-player build |

## 🛠️ Built With

- **Unity** — Game engine
- **C#** — Scripting language

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mbroglio/first_preson_shooter__high_school_project.git
   ```
2. Open the desired folder (`Game`, `Server`, or `SinglePlayer`) as a Unity project.
3. Hit **Play** in the Unity Editor to run the game.
